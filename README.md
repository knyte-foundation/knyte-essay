# Knyte Essay
Планы, эссе, размышления на тему реализации семантических инструментов в концепции *knyte web + knoxel space*. По сути это корневой репозиторий для всех остальных разработок по этой теме.

## Как работать с форматом WPN
Это специальный текстовый формат для работы с планами, подсветка для него доступна в репозитории [work-plan-notation](https://github.com/knyte-foundation/work-plan-notation).
